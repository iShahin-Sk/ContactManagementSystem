# Simple Contact Management System

A simple web application for managing contacts with separate Admin and User panels.

## Features
- Add, search, update, and delete contacts
- Separate Admin and User panels
- Input validation
- Save contacts using browser localStorage
- Export contacts to CSV

## Technologies Used
HTML, CSS, JavaScript

## How to Use
Open the live demo link in your browser to access the application.

## Note
This project uses browser localStorage and does not require a backend or database.
